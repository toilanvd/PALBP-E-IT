# PALBP-E-IT

Assembly line balancing with parallel workstations, minimizing idle time (primary objective) and minimizing the product of #workstations and cycle time (secondary objective)

* Test configuration:

The first line is the number of tasks M.

The second line is the maximum allowable workers on the line N^{hat}.

The next M lines describe the tasks, each line contains the task time for a task as the 4th number on the line.

The next line is the number of edges in the precedence graph.

Last lines each contains two numbers u, v which describe an edge from u to v in the precedence graph.
